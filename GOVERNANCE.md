# Governance

TrialTrace is maintained by Byungwoong Yoo. The maintainer sets release scope, reviews contributions, protects the public-data boundary, and makes final decisions on changes to the API and frozen corpus.

Project decisions should be discussed in public issues or pull requests when they do not involve a security report or private information. Decisions consider reproducibility, source traceability, user impact, maintenance cost, and compatibility with the stated data licenses. Material decisions are recorded in the relevant issue, pull request, or changelog entry.

Contributors earn responsibility through sustained, accurate review and implementation. If additional maintainers are appointed, their scope and repository permissions will be recorded here. A maintainer with a conflict of interest should disclose it and ask another qualified reviewer to decide when one is available.

The project may be archived if it can no longer keep its dependencies secure or describe the corpus honestly. An archived release will remain clearly marked as frozen and unsupported.
