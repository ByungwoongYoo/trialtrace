# Security policy

## Supported versions

Security fixes are applied to the latest `0.1.x` release while TrialTrace remains in the 0.1 series.

## Report a vulnerability

Please use the repository's [private security advisory form](https://github.com/ByungwoongYoo/trialtrace/security/advisories/new). Include the affected version, a reproducible description, likely impact, and any suggested mitigation. Do not include personal or sensitive clinical-trial information; TrialTrace should contain only the bundled public derived corpus.

The maintainer will acknowledge every vulnerability report within 14 calendar days, coordinate a fix and disclosure date when the issue is confirmed, and credit reporters who want public attribution. Confirmed medium-or-higher vulnerabilities will be fixed as quickly as practical and will not remain unpatched for more than 60 days. Critical vulnerabilities receive immediate priority. Routine bugs and data questions belong in the public issue tracker.

The private advisory channel is visible to the reporter, repository administrators and security managers, and advisory collaborators. Do not place a vulnerability in a public issue before coordinated disclosure. The project's security boundaries and current mitigations are documented in [`docs/SECURITY_DESIGN.md`](docs/SECURITY_DESIGN.md).
