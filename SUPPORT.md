# Support

Use the [issue tracker](https://github.com/ByungwoongYoo/trialtrace/issues) for usage questions, reproducible bugs, or data discrepancies. Include the TrialTrace version, operating system, Python version, command or endpoint, NCT identifier when relevant, expected behavior, and actual error.

TrialTrace is a research software project without a guaranteed response time. For a possible vulnerability, follow `SECURITY.md` and use a private security advisory.
